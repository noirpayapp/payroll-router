# Deployments

One JSON file per chain id, written by `script/Deploy.s.sol`: `{ "chainId": …, "NoirpayRouter": "0x…" }`.

No mainnet deployment yet. When the router is live on Robinhood Chain (4663) the address is published here, on
[docs.noirpay.app](https://docs.noirpay.app/protocol/contracts) and on [noirpay.app](https://noirpay.app), all three at once.
An address that appears in only one place is not ours.
